## یەکجار ڕێکدەخرێت

1. بچۆ ناو <bdi dir="ltr">app.pagescms.org</bdi> و بە هەژماری <bdi dir="ltr">GitHub</bdi>ی خۆت بچۆ ژوورەوە.
2. پڕۆژەی <bdi dir="ltr">dindar-website</bdi> هەڵبژێرە.

## نوێکردنەوەی دەق

1. لە لیستەکە **Website text** بۆ زمانی دڵخوازت هەڵبژێرە: English، Kurdish، Arabic یان Persian.
2. بەشەکە بکەرەوە (بۆ نموونە <bdi dir="ltr">Home page: top</bdi> یان <bdi dir="ltr">Case studies</bdi>)، دەقەکە بگۆڕە.
3. دوگمەی <bdi dir="ltr">Save</bdi> بکە.
4. 2 تا 3 خولەک چاوەڕێ بکە، پاشان <bdi dir="ltr">dindarahmed.com</bdi> نوێ دەبێتەوە.

هەر دەقێک لە چوار زمانەکە هەیە. ئەگەر یەکێکیان گۆڕی، لە ئەوانی دیکەش بیگۆڕە، دەنا ماڵپەڕەکە لە زمانەکان جیاواز دەبێت.

## لۆگۆی کڕیار زیاد بکە

1. وێنەی لۆگۆ ئامادە بکە: <bdi dir="ltr">256x256</bdi>، <bdi dir="ltr">WebP</bdi> یان <bdi dir="ltr">PNG</bdi>.
2. لە <bdi dir="ltr">Client logos</bdi> (بەشی وێنەکان) باری بکە.
3. بچۆ ناو <bdi dir="ltr">Client logos</bdi> (لە لیستی نوێکردنەوە)، بەشی کڕیارەکە بکەرەوە، لۆگۆیەکی نوێ زیاد بکە: ناوی براند و ناوی فایل بە شێوەی <bdi dir="ltr">food/brand.webp</bdi>.
4. <bdi dir="ltr">Save</bdi>.

## وێنەی نوێ

1. لە <bdi dir="ltr">Photos</bdi> باری بکە.
2. لە بەشی ئەو شوێنەی وێنەکە تێدا دەبێت، ناوی فایلەکە بنووسە لە خانەی <bdi dir="ltr">Image file name</bdi> (بۆ نموونە <bdi dir="ltr">work-19.jpg</bdi>).
3. <bdi dir="ltr">Save</bdi>.
